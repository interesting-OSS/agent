聚合云图库
2026-03 ~ 2026-05 | http://103.236.64.202/
基于 Spring Boot+Redis+COS+AI+WebSocket 的图片素材网。分为公共图库、个人空间、团队空间。用户可以在平台上传和检索图片素材，管理员可以批量上传、审核、管理、分析图片。
核心技术
权限管控：基于 Sa-Token 实现 RBAC 方法级权限校验；结合分段锁 + 编程式事务控制空间创建权限与存储额度，依托声明式事务保证批量数据操作原子性。
对象存储与缓存优化：搭建 Redis+Caffeine 多级缓存，优化主页接口响应速度并防范缓存雪崩；封装 COS 对象存储服务，实现图片秒传，对图片进行压缩和缩略图转化，降低下载开销，同时结合数据沉降，对 30 天未访问的图片进行自动降频存储，节约存储成本。
实时协同编辑：基于 WebSocket + 事件驱动设计实现多人协同编辑图片功能，自定义握手拦截器确保权限通过后才能连接，并通过 “编辑锁” 机制，避免编辑冲突。
以图搜图：利用 Jsoup 和 HttpClient 调用百度搜图 API，并运用门面模式组合 API 调用来获取图片列表，便于客户端使用。
AI 扩图：调用阿里云百炼大模型封装 AI 绘图服务，提供创建与查询任务的 API，采用异步任务轮询处理进度，并统一错误码以提升稳定性。

2025-12 ~ 2026-02

核心技术

RAG 检索增强问答：基于阿里云知识库构建检索增强能力，配置相似度阈值与元信息过滤策略，提升 AI 回复的准确性与相关性。
实现 AI 工具调用：利用 Spring AI 的工具 @Tool 注解定义了多种工具调用功能，包括文件操作、联网搜索、网页抓取、终端操作、资源下载和 PDF 生成。自定义图片搜索 MCP 服务，实现图片资源检索能力。
多推理模式智能体：基于 CoT + ReAct 双模式构建自主规划智能体，支持复杂任务拆解、工具调用与多轮执行，实现端到端自动化任务闭环。
解决 Agent Loop 死循环：基于 Agent Loop 思想实现了 AI 智能体的自主多步骤执行，并通过最大步骤限制、Agent 状态管理和死循环检测，防止智能体陷入无限循环。

恋爱咨询助手
项目周期：2025-09 ~ 2025-12
项目介绍
基于 Spring Boot3 + Spring AI + RAG + ToolCalling + MCP 的企业级 AI 智能体，支持多轮上下文对话、对话记忆持久化、知识库 RAG 检索增强；依托 ReAct 推理范式自主拆解任务、调用外部工具，完成联网检索、文档生成、计划编制等复杂需求。
主要实现

自定义 VectorStore 适配实现，对接 EmbeddingModel 向量化文档数据并存入 PGVector 向量库，支持语义相似度检索 + 多维度元数据过滤，优化知识库召回精度。
借助 SpringAI @Tool 工具注解封装文件处理、网页爬虫、联网搜索、PDF 导出等工具能力，拓展 Agent 外接资源的能力边界。
融合 CoT 思维链 + ReAct 双推理架构，搭建自主决策智能体，实现任务拆解、工具选型、循环迭代执行，可根据用户需求自动检索约会资源、生成约会规划 PDF 文档。
参考 OpenManus 分层设计，抽象 BaseAgent、ReActAgent、ToolCallAgent 三层智能体架构，提升代码复用性、模块扩展性。
